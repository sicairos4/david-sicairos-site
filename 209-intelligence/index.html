        How to read this panel
        Last post is when the last post actually went live (verified receipts only — submits never count). Yellow at the lane's cadence (L), red at twice it (2L) — Threads / Bluesky / LinkedIn L=20m, FB profile L=25m, IG / FB pages / TikTok L=30m, YouTube L=35m. Override at L+10 and diagnoser at 2L−5 are both still due (yellow). Due soon is the pre-fire window: a lane shows DUE SOON from L−10 (fire at 10m for L=20, 15m for the FB profile, 20m for L=30, 25m for YouTube) until it turns yellow — yellow means the pre-fire was missed. STALE means the state file is more than 10 minutes old: a stale snapshot never shows a lane green. Health is the mean across the 18 scored lanes of cadence divided by time since the last verified post, receipts only. The 77% line is the floor: below it the error budget is overdrawn, changes freeze, and the reset ladder runs before any full reset.
        Longest / last / average gap are measured over the last 23 hours from verified publishes.
        Buttons run the reset ladder: Retry (rung 1), Fail over (rung 2), Fire fresh (rung 3), Pause (rung 4), Resume (rung 4, closes the breaker), Rebuild queue (rung 6). Publish buttons queue the request to the cadence coordinator — this panel never fires a post itself. Full reset (rung 8) is gated and needs confirmation.
        Lane controls (above the platforms) is the same ladder in one table, with cadence (L) and fire-at (L−10) per lane. Cadence is displayed, not edited: it lives in the engine (live-state-updater.py + the yellow detector) and this table reads it from live-state.json.
        Queue depth is staged rows ready to post, counted live from the queue files. Below 25 is below the floor and shows in red.
        Open post always goes to the exact post. If the link was never captured, the card says "post link not captured" instead of opening a profile or feed. A comment or reply is never a post — growth rows never set a lane's last-post time.
        Steering is advisory only. It shows what topics are working per profile and system-wide, which way the system is leaning and why, and the balance across lanes. A steer you save is a suggestion the steering writer records, never an order to a publisher.
