209 WORKSTATION

Your day, in one place.

Workstation is a private space to plan, focus and reflect. Use as much or as little as you need. You do not have to complete every section.

Start here

  1. Choose the date you want to work on.
  2. In Today, add one task or use an optional morning routine. Give a task a time only if that helps.
  3. Use the section tabs to switch between planning, Focus and Reflection.
  4. Choose Save selected day to keep account changes. Wait for confirmation before leaving.

Where things are

  • Today: tasks, optional morning routine and time blocks. Scheduling does not mark a task complete.
  • Milestones: outcomes you are working toward, with linked tasks or manual progress.
  • Focus: a timer for one task. Keep the page open; timer completion does not complete the task.
  • Reflection: writing prompts first, then free writing and separate private notes. Skip any prompt.
  • Review: daily closeout and saved-day review/report options. Check the selected date range.
  • Creator desk: a separate writing draft. Nothing is published automatically.
  • Learn: pathways, worksheets and practice tools. Check each tool's saving instructions.
  • Settings: profile, sign-in, appearance, preferences, files and help. Read export/deletion scope before proceeding.
Saving your day versus saving a PDF

Save selected day keeps the loaded account day when the server confirms it. A PDF is a separate personal copy; it does not save planner changes. Selected-day output and saved-date-range reports have different scopes. Review the preview and choose private-writing sections deliberately.

If saving is uncertain, keep or export your edits before reloading. Guest work is not automatically saved into an account. Technical recovery files are separate from ordinary PDF copies.

Reflection, notes and privacy

Prompts help you name a feeling, notice an event, choose a possible next step and keep a reminder. Free writing is a separate journal. Notes and brain dump are optional separate spaces. A lesson is a general takeaway you may explicitly choose to reuse.

Writing is not automatically sent to AI, shared or published. Copies can contain private text: review the scope and destination and keep unencrypted files secure.

Changing days and setting tasks aside

Save work before changing days. A focus view only hides task cards temporarily. Set aside changes a task's area on the same day. The later-day handoff copies selected task text and area; it does not remove source tasks, move blocks or transfer all task metadata. Load its destination, review additions and save that day explicitly.

App window and connection

Use the native Android app or a supported installed web app for a separate app window. A link opened in a browser can show the browser toolbar. External links and sign-in may open separately.

Account loading and saving need a connection. Source changes do not update an already installed Android binary; native welcome-screen changes need a corresponding rebuilt and installed version. Installation does not promise offline saving.

Need help?

Open the short help disclosures within each section or Settings → Help. If reporting a problem, describe the section and action. Do not send passwords, tokens or private journal content.
