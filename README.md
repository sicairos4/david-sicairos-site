# David Sicairos — 209 Control Panel

A lightweight, high-contrast personal operating hub for David Sicairos, 209 Media Connect, 209Audit, dBeastco Wellness, and 209 Systems Studio.

## Live URL

After enabling GitHub Pages:

https://sicairos4.github.io/david-sicairos-site/

## Enable GitHub Pages

1. Open the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch: `main`.
5. Select folder: `/ (root)`.
6. Save.

## Editing

All content is in `index.html`. The site uses one HTML file, inline CSS, and a tiny JavaScript snippet for the year. It avoids external frameworks, large images, autoplay media, and heavy scripts to remain fast on older devices.
