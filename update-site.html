UPDATE SITE

One prompt. Any AI.

The entire site runs on one file: data/site-config.json. Update it with a simple prompt in Muse, Gemini, Perplexity, or any AI that can edit the file—and the site reflects it automatically, in your voice.

BRAND VOICE

Every update sounds like you.

Before editing, any AI should read prompts/brand-voice.md. That file locks in your casual-professional, human, locally grounded voice so every update comes out consistent.

View Brand Voice Guide
HOW IT WORKS

One file. Four things it drives.

data/site-config.json\n ├─ records[] → Homepage records feed\n ├─ featuredStory → Homepage hero\n ├─ museStatus → Muse page status\n └─ announcements[] → Muse page announcements

You never touch code. Just tell any AI what to add or change, and it updates the JSON in your voice.

COPY-PASTE PROMPTS

Prompts you can use in any AI.

Add a record

“Read prompts/brand-voice.md, then add this record to site-config.json: headline: ‘[headline]’, date: ‘[date]’, source: ‘[source]’, link: ‘[link]’.”

Affects: Homepage records feed.

Update the featured story

“Read prompts/brand-voice.md, then update featuredStory in site-config.json: title: ‘[title]’, hook: ‘[hook]’, link: ‘[link]’.”

Affects: Homepage hero.

Update Muse status

“Read prompts/brand-voice.md, then update museStatus in site-config.json: state: ‘[state]’, lastRun: ‘[date]’, nextAction: ‘[next action]’.”

Affects: Muse page status.

Add an announcement

“Read prompts/brand-voice.md, then add this announcement to site-config.json: title: ‘[title]’, body: ‘[body]’, link: ‘[link]’.”

Affects: Muse page announcements.
