Keep your day one tap away.

Add Workstation to your Home Screen. On supported devices, opening that icon runs the web app in its own window without the usual browser toolbar.

Choose the instructions for your device below.

Open WorkstationUse guest planner

Android

  1. Open this installation page directly in Chrome, not inside the old Workstation launcher or another app’s browser.
  2. Use Install Workstation if it appears, or open Chrome’s menu and look for Install app or Add to Home screen.
  3. Choose the app installation option if your browser offers one, then launch the new Workstation icon from your Home Screen.

A simple bookmark may still open browser controls. Availability and wording depend on your browser. This does not modify the existing APK or remove its X button.

iPhone or iPad

  1. Open this page in Safari.
  2. Tap Share, then Add to Home Screen.
  3. Enable Open as Web App if that option is shown, then tap Add.
  4. Launch Workstation from its new Home Screen icon.

This is an installed web app, not an Apple App Store listing. iOS controls the installation interface and icon rendering.

What works—and what still needs a connection

Uses the same website and backend. Sign-in, account loading and saving still require a network connection. Installation does not copy an existing session from the browser-backed APK or fix native OAuth callbacks.

The service worker supplies a connection-error page only. It does not cache planner pages, private API replies, attachments or account data, and it does not add offline saving.

Installing does not move or merge guest work. Export unfinished work before changing browsers or removing any old preview app. External sign-in or out-of-scope links may show browser controls.
