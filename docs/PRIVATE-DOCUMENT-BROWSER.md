# Private document browser — source integration

Integrated into audit-workspace.html and gated by the existing signed-in private desk. No private data is committed, imported or published. No migration or permissions change is included. Tests and deployment/runtime verification are deferred.

Account mode reads audit_archive_documents under explicit owner_id filtering and existing RLS. It includes Drive IDs, metadata filters and 20-card pagination. It withholds an incomplete account index at the 20,000-row ceiling. Empty account records do not mean an empty Drive archive. Document date falls back to received_at; UI labels it Source date, not an inferred legal/document date. Request references remain labels, not confirmed relationships.

Optional page-text mode explicitly opens archive-search-index.json and its matching catalog in memory only. The user attests authorization; snapshot ownership is not cryptographically/account verified. Each JSON input is capped at 64 MiB, document lists at 20,000. Drive IDs, page locators and file-label set matching are validated; metadata-only and unavailable-text rows remain browsable. Only text_status ok is searched. All required literal terms must occur together in metadata or together on a page. A card shows its first matching page, not every matching page. Counts refer to references/copies, not unique document hashes or confirmed vendor relationships. Missing/excluded counts are coverage, not query matches. No OCR is performed and the presence of some text does not establish every page was extracted.

The files are not uploaded, persisted in browser storage, or saved to an account. Snapshots/results clear on account changes, root hiding, page exit and explicit Close snapshots. Source-file digests identify the opened snapshots, not original PDF integrity. Data is rendered as text, not record-supplied HTML. Drive links are constructed from validated IDs with noreferrer. The account reload also clears local snapshots. This is a browser convenience, not a substitute for private backend page-text persistence or an access-control system for local files.

Required remaining work: obtain the actual approved integration package and import exact owner-scoped records; private page-text storage/query endpoint; index generation/OCR status; normalization and confirmed relationship mapping; broader archive coverage. The website will not automatically fetch Muse workspace files or populate 88 metadata rows from this code. Public Files remains published-only and does not receive private originals or excerpts. Personal CHP publication hold remains intact.
