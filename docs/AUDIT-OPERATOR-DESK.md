# 209 Audit operator desk

Source implementation of an owner-scoped interface over existing audit_archive_documents, audit_archive_requests and audit_archive_events. The connected database metadata supplied these table/column definitions and reported RLS enabled. Policy/function definitions were not retrieved: the read-only SQL metadata query was blocked by the connector approval gate and did not execute. No database migration, grants, storage operation or record write was performed while preparing this source.

The private page is audit-workspace.html (noindex/nofollow, no-referrer). Only a footer link is added to the existing public Audit page. Homepage, toolbar, public catalog and private Workstation are unchanged. The existing account SDK supplies identity; every archive read is explicitly owner-filtered and checked against the current account before and after network work. Pages are read in batches of 200 with a 20,000-row per-table ceiling; exceeding it with no final short page withholds the incomplete index rather than presenting a partial total. This is not a consistent cross-table snapshot.

Features: list/filter private metadata, add document references, add requests, display source-linked timeline entries, append timeline/correction notes, update request status/next action with loaded-version matching, and deliberately export one private request log plus its linked metadata. Inputs are rendered through textContent, not record-supplied HTML. Document/reference creation defaults to private, unreviewed, file_state none. Reference labels alone never establish a relationship; timeline document links are explicit owner-scoped IDs. Mutation responses must return a row; uncertain/failed results are not automatically retried. Existing server policies and triggers may deny an operation; the UI does not relax or bypass them.

The desk does not fetch original URLs, upload/store document bytes, calculate original checksums, send CPRA emails, infer legal deadlines, change public visibility, publish records, fabricate filings, connect private records to public requests, or certify redactions. The JSON log is an unencrypted operator export, not a personal-planner output change and not a PDF/source-file archive. Original-file upload, controlled redacted-release workflow, substantive CEDS research, real filings collection and public record publication remain separate work. The whole Audit backlog is not marked complete.

Account changes and pagehide clear loaded private content/form drafts. Reload and request selection warn about relevant unsubmitted drafts. Account sign-in opens the existing login in another tab; return and load the archive. This source does not establish deployed ownership-policy correctness or successful live persistence. No tests, device checks, collection, workflow dispatch, production build or publication were run for this batch. Existing workflows remain unchanged.
