# Public store and planning-resource batch

Replaces the store's horizontal oversized rails with compact wrapping grids and removes carousel controls/handlers. Retains existing product URLs and Ecwid store ID. The embedded catalog initializes only after the user opens its details section; hosted store and product fallbacks remain available. No checkout transaction, payment provider activation or price claim is introduced.

planning.html provides an actual Morning resource landing page, editable same-day routine preview, daily schedule worksheet, Monday-start week and month worksheets, print control and script-free HTML worksheet download. Date arithmetic uses device-local calendar dates, not UTC conversion. Notes remain in page memory until an explicit local download/print; no account upload or analytics script is added. This is a public worksheet resource, not an alternative saved-member planner or a claim that paid courses/videos/kits have shipped.

Direct links connect store, planning resources, existing learning pathways and the account-backed Workstation. Third-party catalog availability, actual customer checkout and public deployment still need observed acceptance. No APIs/secrets, private records, migrations or publishing channels were changed.
