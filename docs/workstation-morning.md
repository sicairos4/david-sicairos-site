# Intentional Morning → optional Intentional Day

This is a morning-first interface candidate on the release branch. It previews five brief default steps, lets the user enable, rename, change durations, or reorder them using accessible buttons, and can hand the selected steps to the existing day block form. The full day is optional; no automatic rollover or background scheduling is claimed.

The guidance is deliberately non-punitive: start small enough to repeat, protect sleep and rest, review one priority, and increase effort only when a small step becomes dependable. A missed step is information, not failure. Consistency is built through repeatability and flexible adjustment, not a streak requirement or a large initial leap.

The morning preview is not saved as an independent account record. Added schedule blocks are unsaved until the existing Save selected day succeeds. Existing private journal, lesson and task data are not intentionally overwritten. The pure handoff checks overlap before returning blocks; the UI uses the existing block form and its validation. Browser and real-account tests remain necessary.

This is not drag-and-drop, sleep protection, undo or a verified account-backed routine editor. The existing app's save/reload and the Android-hosted layout must be tested after deployment.
